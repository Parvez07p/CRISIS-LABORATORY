📜 Arena Rules

Welcome to the Crisis Laboratory Debugging Arena. Read the rules carefully before entering.

🎯 Competition Overview

  • The competition consists of 50 debugging challenges across HTML, CSS, and JavaScript.
  • Each challenge contains a broken webpage that you must inspect, debug, and repair.
  • Once all bugs are fixed correctly, the webpage reveals a hidden flag.
  • Submit the flag using the format AIODYSSEY{challenge_name} to earn points.
  • The competition runs for 90 minutes with auto-submission when time expires.

📋 Challenge Format

  • Each challenge includes a problem description and clear objective.
  • Broken HTML, CSS, and JavaScript code is provided for inspection.
  • Challenges are categorized as Easy (50pts), Medium (100pts), or Hard (200pts).
  • Challenge 50 is the "Master Debug Arena" boss challenge worth 500 points.
  • Each challenge has up to 2 hints available (using hints reduces bonus points).

🏆 Scoring System

  • Base Points: Easy (50), Medium (100), Hard (200), Boss (500)
  • First Blood Bonus: +25 points for being the first to solve a challenge
  • No Hint Bonus: +20 points for solving without using any hints
  • Perfect Solve: +30 points for fixing all bugs without errors
  • Time Bonus: +10 points for every 5 minutes remaining
  • Maximum Score: 6000+ points available

🔧 Debugging Rules

  • Participants may inspect and modify the HTML, CSS, and JavaScript files.
  • Do NOT modify the flag validation logic or flag values.
  • Using browser developer tools (F12) is encouraged for debugging.
  • External resources, libraries, or frameworks are NOT allowed.
  • Each challenge must be solved independently without sharing solutions.

🏅 Badges & Achievements

  • First Blood: Earned by solving any challenge first
  • Bug Hunter: Solve 10+ challenges
  • CSS Wizard: Solve all CSS challenges
  • JavaScript Ninja: Solve all JavaScript challenges
  • DOM Master: Solve 20+ challenges
  • Pixel Perfect: Perfect score on any challenge
  • Accessibility Hero: Solve accessibility challenges without hints
  • Performance Guru: Solve performance challenges within time bonus
  • Debug King: Solve 40+ challenges
  • AI Odyssey Champion: Complete all 50 challenges

⚡ Fair Play Guidelines

  • No automated scripts or bots are allowed for flag submission.
  • Do not attempt to brute-force flags or manipulate the scoring system.
  • Any form of cheating will result in immediate disqualification.
  • Admin decisions are final and binding.
  • Respect other participants and maintain a positive competition environment.

⏱️ Timer & Submission

  • The 90-minute timer starts when you begin your first challenge.
  • All progress is auto-saved to your browser's local storage.
  • When time expires, your current progress is auto-submitted.
  • You can view the live scoreboard to see your ranking.
  • Admin can start/stop the timer and manage challenges.
